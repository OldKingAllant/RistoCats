This is the API

getDishProp

Get properties of specific dish

URL

//api/menu/{dishid}/properties

HTTP Method

GET

Response Type

Dish

Parameters

  • Query: lang String

    Language

  • Path: dishid String

getMenu

Returns the current menu or all dishes

URL

//api/menu/overview

HTTP Method

GET

Response Type

List

Parameters

  • Query: lang String

    Language

  • Query: filter_enable Boolean

    If true, returns only dishes that are currently inserted in the menu

modifyMenu

Add or remove dishes from menu

URL

//api/menu/modify

HTTP Method

PUT

Response Type

Parameters

  • Body: body List(menu_modify_body)
